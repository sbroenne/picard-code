  1. In a terminal in the Picard Code folder, run npm run opencode.
  2. Type /connect and choose GitHub Copilot.
  3. Open GitHub's device sign-in, check your account, and enter the code OpenCode gives you.

Your account needs Copilot access. A GitHub command-line sign-in does not connect Copilot. No password or token is entered here.
