# Getting help

Use [Discussions](https://github.com/sbroenne/picard-code/discussions) for setup
questions, speech-model suggestions, and conversations about the computer's
character. Check [Get started](README.md#get-started) and
[If something goes wrong](docs/USER_GUIDE.md#if-something-goes-wrong) first.

Use the [bug form](https://github.com/sbroenne/picard-code/issues/new/choose)
for a reproducible problem. Include your operating system, browser, Picard Code version or commit,
selected model provider and speech services, steps, and the exact error.
Share a small example, not your private project or complete log entry.

Do not share credentials, local settings, other people's speech, or a launch
address containing its temporary key. For sensitive problems, follow
[SECURITY.md](SECURITY.md), not Discussions.

Picard Code is maintained in spare time. Help is welcome, but response times
and acceptance of feature requests are not guaranteed. Provider access,
Azure billing, and third-party model availability are controlled by those
services, not this project.
